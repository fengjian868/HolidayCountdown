# 🎉 节假日倒计时 (HolidayCountdown)

&gt; 一个为 [ClassIsland](https://github.com/ClassIsland/ClassIsland) 开发的插件，在班级多媒体大屏上显示距离最近节假日的倒计时。

---

## ✨ 功能特性

- 📅 **实时倒计时** — 自动计算并显示距离下一个节假日的剩余天数
- 🌐 **网络同步** — 从 [timor.tech](https://timor.tech/api/holiday/year/2025) 实时同步国务院发布的最新节假日安排（含调休补班信息）
- 💾 **本地缓存** — 网络数据本地缓存 7 天，减少重复请求，离线也能用
- 🛡️ **内置保底** — 网络失败时自动回退到内置的 2025-2028 年节假日数据
- 🎨 **原生视觉** — 采用 ClassIsland 原生组件风格，无缝融入主界面
- 🔄 **自动刷新** — 每分钟自动更新，无需手动操作

---

## 🔧 开发说明
技术栈
.NET 8.0 + WPF
ClassIsland.PluginSdk 2.0.3.2
HttpClient + System.Text.Json

## 核心逻辑
插件启动
  ├─ 加载内置节假日数据（保底）
  ├─ 检查本地缓存（7天有效）
  └─ 后台请求 timor.tech API（只请求一次）
       ├─ 成功 → 解析JSON → 更新列表 → 写缓存
       └─ 失败 → 继续使用缓存/内置数据

显示更新（每分钟）
  └─ 过滤已过去日期和调休上班日
     └─ 取最近一个节假日 → 计算天数差 → 更新UI

## 数据源
网络：https://timor.tech/api/holiday/year/{年份} — 来自国务院公告
内置：2025-2028 年元旦、春节、清明、劳动节、端午、中秋、国庆

## ⚠️ 常见问题
Q: 插件显示 "暂无节假日"
>检查系统时间是否正确。如果当前日期在所有节假日之后，会显示此提示。插件会自动加载未来年份的数据。
Q: 安装后报 "Dependency resolution failed"
>漏掉了 HolidayCountdown.deps.json 文件。这是编译生成的依赖解析文件，必须和 .dll 一起复制。
Q: 显示 "(本地)" 而不是 "(网络)"
>首次启动时网络请求是异步的，可能界面先显示了本地数据。等待 1-2 分钟后会自动刷新为网络数据。如果网络不通（如学校内网限制），会一直保持本地数据。
Q: 农历节日日期不对
>网络同步模式下以 timor.tech 返回的公历日期为准。如果处于离线状态使用内置数据，农历节日的公历日期是硬编码的近似值，可能与实际放假安排有 1-2 天偏差。
