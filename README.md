# 节假日倒计时插件

## 功能模块

* **节假日倒计时** - 显示距离最近节假日的倒计时，支持弧形进度环、调休提醒、放假天数

* **24节气倒计时** - 显示当前节气及下一个节气倒计时，支持自定义颜色、进度环开关

* **农历日期显示** - 支持多种显示格式（完整/简洁/含生肖/含节气），可自定义模板，年度缓存

* **自定义节日倒计时** - 添加你自己的节日（生日、纪念日等），支持每年重复

* **寒暑假倒计时** - 显示距离暑假/寒假的剩余时间（周+天）

* **问候语** - 显示时段问候、放学提醒、特殊日期问候等

* **天气问候** - 读取 ClassIsland 天气，1分钟刷新，含温度穿衣提醒、预警、下雨/停雨倒计时，支持模板自定义排版

* **智能天气** - 比 ClassIsland 原版更美观的天气组件，含彩色图标与预警

* **大考倒计时** - 显示中考/高考倒计时，内置全国各地考试时间，每年自动刷新

* **世界时钟** - 显示多个国家/城市的时间，默认北京时间，最多5个城市

* **学习时长统计** - 记录 ClassIsland 运行时长，显示今日学习时长

* **课程表联动\[测试版]** - 读取 ClassIsland 课程表，显示当前课程/下节课信息或课间倒计时

* **天气变化提醒\[测试版]** - 模仿 Windows 小组件天气的变化提示，如"附近有闪电""几点后会下雨"

## 使用说明

### 节假日倒计时组件

* 自动显示最近的节假日及倒计时

* 首个节日可显示弧形进度环（圈内显示日期）

* 支持调休上课提醒

* 显示该节日放假天数

### 自定义节日

* 在设置页添加你的节日（支持每年重复）

* 组件会横向排列显示多个节日

### 问候语设置

* **时段文案**：自定义多个时间段的问候语（如早/中/晚），留空则使用本地数据库每日随机

* **特殊日期**：设置特定星期几的问候语，可指定时段（如"周五下午"）

* **每周提醒**：选择每周某一天显示提醒，内置 230+ 条按标签分类文案

* 特殊日期优先级高于时段文案

### 农历设置

* 选择预设格式或自定义模板

* 可用变量：`{gzYear}` 干支年、`{IMonthCn}` 农历月、`{IDayCn}` 农历日、`{Animal}` 生肖、`{Term}` 节气

* 开启自动刷新后会缓存一整年数据

### 天气问候设置

* **排版**：选择预设模板或自定义模板

* **温度提醒**：自定义各温度区间的穿衣提醒

* **天气关键词**：根据天气关键词匹配显示文案

* 可用变量：`{greeting}` 问候语、`{temp}` 温度、`{weather}` 天气、`{warning}` 预警、`{icon}` 天气图标

### 课程表联动

* 自动读取 ClassIsland 当前课程表

* 上课中显示课程名和剩余时间

* 课间显示倒计时和下节课名

* 放学后显示"放学了"

### 学习时长统计

* 自动记录 ClassIsland 运行时长

* 每 30 秒更新一次

* 本地存储最近 30 天数据

* 显示今日学习时长
