# 智能天气组件设计方案

## 背景与目标

ClassIsland 自带的天气组件信息单一，图标为黑白风格，且预警信息不够醒目。本项目需要新增一个**智能天气组件（SmartWeatherComponent）**，与现有天气问候组件共存，提供更丰富的天气展示：

- 保留读取 ClassIsland 内置天气服务的能力。
- 增加国家通用气象预警信息，使用醒目徽章形式展示。
- 为晴天、雨天、雪天等天气图标添加颜色，避免黑白单调样式。
- 下雨时统一使用雨滴风格图标并应用蓝色调。
- 将所有模板变量集中管理，使用 `{A}`、`{B}`、`{C}`、`{D}`、`{E}` 简写，避免用户混淆。

## 方案选择

采用**图标+文字组合面板（方案二）**：使用横向 `StackPanel` 排列多个独立 `TextBlock` 徽章，每个徽章可独立控制颜色、字号、圆角背景。该方案实现灵活，能做出明显的预警徽章效果，同时性能开销可控。

## 组件架构

### 文件位置

- `Views/Components/SmartWeatherComponent.xaml.cs`：新组件主文件。
- `Plugin.cs`：注册新组件。
- `Models/PluginSettings.cs`：新增智能天气相关设置字段。
- `Views/SettingsPages/UnifiedSettingsPage.xaml.cs`：在「天气」Tab 中新增设置分组。

### 组件信息

- GUID：`A1B2C3D4-E5F6-7890-1234-567890ABCDEF`（需确保唯一，不与现有组件冲突）。
- 名称：智能天气
- 简介：比原版更美观的天气组件，含彩色图标与预警

## 变量映射

所有变量在组件内部通过 `SmartWeatherVariables` 类统一生成：

| 变量 | 含义 | 示例 |
|------|------|------|
| `{A}` | 温度文本 | `26°C` |
| `{B}` | 彩色天气图标 | `☀️`（晴，黄色） |
| `{C}` | 预警信息徽章组合 | `🌀 台风 橙` |
| `{D}` | 穿衣/出行提醒 | `很热，短袖即可` |
| `{E}` | 数据状态 | `（天气未刷新）` |

默认模板：`{A} {B} {C} {D}`

## 视觉设计

### 布局

```
┌─────────────────────────────────────────┐
│  26°C  ☀️  [高温 橙]  很热，短袖即可      │
└─────────────────────────────────────────┘
```

- 整体为横向 `StackPanel`，元素间距 6，垂直居中。
- 每个变量渲染为一个 `Border` 包裹的 `TextBlock`（徽章样式），除 `{B}` 天气图标外默认无底色。
- 预警 `{C}` 中每个预警独立为一个圆角小徽章，包含图标、类型、级别，带有对应级别底色。

### 天气图标与颜色映射

| 天气关键词 | 图标 | 颜色 |
|-----------|------|------|
| 晴 / 高温 | ☀️ | `#FFA500` |
| 多云 | ⛅ | `#FFD700` |
| 阴 | ☁️ | `#90A4AE` |
| 雨 / 阵雨 / 暴雨 / 小雨 / 中雨 / 大雨 | 🌧️ | `#2196F3` |
| 雷阵雨 | ⛈️ | `#5C6BC0` |
| 雪 / 小雪 / 大雪 / 暴雪 | ❄️ | `#81D4FA` |
| 雾 / 霾 | 🌫️ | `#B0BEC5` |
| 风 / 沙尘 / 大风 | 🍃 | `#8D6E63` |
| 冰雹 | 🧊 | `#42A5F5` |
| 默认 | 🌤️ | `#FFD54F` |

下雨判断规则：天气文本包含「雨」或「阵雨」或「雷阵雨」时，统一使用 🌧️ 或 ⛈️ 并应用蓝色系。

### 预警徽章设计

预警从 ClassIsland 天气数据 `Alerts` 集合中解析标题，提取类型与级别。

支持的预警类型：
- 暴雨、台风、雷电、大风、暴雪、寒潮、大雾、沙尘、冰雹、高温、干旱、霜冻、道路结冰、霾

支持的级别与底色：

| 级别 | 底色 | 文字颜色 |
|------|------|----------|
| 红色 | `#F44336` | `#FFFFFF` |
| 橙色 | `#FF9800` | `#FFFFFF` |
| 黄色 | `#FFEB3B` | `#000000` |
| 蓝色 | `#2196F3` | `#FFFFFF` |
| 未识别级别 | `#9E9E9E` | `#FFFFFF` |

徽章样式示例：`🌀 台风 橙`

### 温度颜色

开启「温度按冷暖自动变色」后：

| 温度范围 | 颜色 |
|----------|------|
| ≥ 35°C | `#F44336`（热） |
| 25 ~ 34°C | `#FF9800` |
| 15 ~ 24°C | `#4CAF50`（舒适） |
| 5 ~ 14°C | `#2196F3` |
| < 5°C | `#3F51B5`（冷） |

关闭时使用主题默认文本色。

## 数据流

1. 组件初始化时启动 `DispatcherTimer`，每分钟刷新一次。
2. 通过反射读取 `ClassIsland` 的 `SettingsService.Settings.LastWeatherInfo`。
3. 解析 `Current` 对象获取温度、天气代码、天气文本。
4. 解析 `Alerts` 集合获取所有预警标题。
5. 根据温度和天气文本生成 `{A}`、`{B}`、`{C}`、`{D}`、`{E}`。
6. 按用户模板替换变量并渲染到界面。

## 设置项

在统一设置页「天气」Tab 中新增「智能天气」分组：

| 设置项 | 类型 | 默认值 |
|--------|------|--------|
| 智能天气模板 | TextBox | `{A} {B} {C} {D}` |
| 显示温度 {A} | ToggleSwitch | true |
| 显示天气图标 {B} | ToggleSwitch | true |
| 显示预警 {C} | ToggleSwitch | true |
| 显示穿衣提醒 {D} | ToggleSwitch | true |
| 显示更新状态 {E} | ToggleSwitch | false |
| 预警置顶 | ToggleSwitch | true（有预警时优先完整显示） |
| 温度按冷暖变色 | ToggleSwitch | true |

## 兼容性

- 新组件与 `WeatherGreetingComponent` 完全独立，不影响现有天气问候组件。
- 继续使用 `HolidayService` 中的天气数据读取逻辑，保持与 ClassIsland 的天气服务兼容。
- 不引入外部图片资源，所有图标使用 Emoji/Fluent 字符，降低打包复杂度。

## 风险与回退

- 如果 ClassIsland 天气数据结构变化，可能导致数据读取失败。组件需捕获异常并显示「天气数据不可用」。
- 预警级别解析依赖标题中包含「红/橙/黄/蓝」字样，若未来数据源变更需同步更新解析规则。
